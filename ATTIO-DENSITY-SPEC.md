# Спецификация: перевод компонентов shadcn на плотность Attio

Все числа ниже **замерены по пикселям** на кадрах живого интерфейса Attio
(`research/attio-product-shots/`, 99 кадров из публичной справки, 20.09.2026).
Это не вкус и не предположение. **Ничего не додумывать: если значения для случая
нет в этой таблице — оставить как есть и написать об этом в отчёте.**

Тема уже описана в `src/app/globals.css`. Токены существуют — задача перевести
компоненты на них, а не заводить новые.

## Токены, которыми надо пользоваться

| Токен | Значение | Что это |
|---|---|---|
| `--h-control` | 28px | высота кнопки, поля, селекта, триггера |
| `--h-control-sm` | 26px | компактный чип-фильтр |
| `--h-row` | 36px | строка таблицы |
| `--h-row-header` | 39px | шапка колонок |
| `--h-header` | 48px | шапка страницы |
| `--h-toolbar` | 49px | полоса действий |
| `--px-cell` | 12px | боковой отступ ячейки |
| `--radius` | 6px | скругление контролов |
| `--border` | `#eeeff1` | линии сетки и разделители |
| `--input` | `#edeef0` | рамка поля и вторичной кнопки |
| `--primary` | `#3b6ce8` | синий акцент |
| `--primary-border` | `#3561d0` | собственная тёмная рамка синей кнопки |
| `--accent` | `#f1f2f3` | фон при наведении |
| `--muted-foreground` | `#999999` | тихий текст |
| `--foreground` | `#242529` | основной текст |

Вторичный текст и заголовки колонок — `#606164`, 13px.

## Правила замены

1. **Высоты.** Любые `h-7`, `h-8`, `h-9`, `h-10`, `size-8`, `size-9` на контролах
   (кнопка, поле, селект, триггер, пункт меню) → `h-[var(--h-control)]` или
   `size-[var(--h-control)]`. Компактные варианты (`sm`, `xs`) →
   `h-[var(--h-control-sm)]`. Высоты внутри иконок (`size-4`, `size-3.5`) не трогать.
2. **Цвета.** Жёстко зашитые цвета и `oklch(...)` → на семантические токены выше.
   `hover:bg-muted/50` и подобные полупрозрачные наведения → `hover:bg-accent`:
   на белом фоне Attio наведение это сплошной серый, а не прозрачность.
3. **Скругления.** `rounded-md`, `rounded-lg` на контролах оставить — они уже
   считаются от `--radius: 6px`. Не заменять на числа.
4. **Текст.** Основной размер в интерфейсе — 14px (`text-sm`). Вторичный и
   служебный — 13px (`text-[13px]`). Заголовки и подписи капслоком Attio не
   использует — если встретится `uppercase`, убрать.
5. **Тени.** У Attio мягкая лестница: чёрный на 1–7% прозрачности, тень
   расходится, но не темнеет. Для оверлеев (меню, поповер, диалог) —
   `shadow-[0_8px_16px_-4px_rgba(0,0,0,.04),0_2px_4px_-1px_rgba(0,0,0,.02)]`.
   Более жирные тени shadcn заменить на эту.
6. **Тёмная тема.** Классы `dark:*` **не трогать вообще**. Тёмную тему Attio мы не
   снимали, подставлять туда выдуманные значения запрещено.

- Менять логику, пропсы, структуру компонента, имена экспортов.

- Заводить новые CSS-переменные.
- Придумывать значения, которых нет в таблице выше.
