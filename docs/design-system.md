# Дизайн-система «Фарфор»

Один визуальный закон для всех экранов CRM с 24.09.2026. Поведение и пустые состояния —
`docs/ux-contract.md`, он остаётся в силе. Здесь — как экран выглядит и двигается.

Эталон: `.scratch/design/e2-reference.png` (кадр `dir-e2-farfor-plotnee.html`) и принятый
экран воронки `.scratch/design/deals-accepted.png`. Если сомневаешься — делай как на воронке.

## 1. Идея в одной фразе

Серый фарфор, на нём модули, в модулях светлые плитки. Всё, что можно нажать, — пилюля.
Один лаймовый цвет действия. Заголовки крупные и тонкие. Интерфейс отвечает на каждое
наведение и нажатие мягким, быстрым движением.

## 2. Файлы

| Файл | Что в нём | Кто правит |
|---|---|---|
| `src/styles/tokens.css` | все токены | только мозг |
| `src/styles/shell.css` | острова, навигация, появление экрана, фокус, reduced motion | только мозг |
| `src/styles/components.css` | примитивы: модуль, плитка, кнопки, поля, пилюли, меню | только мозг |
| `src/styles/kit.css` | анимации, скелетоны, пустые состояния, инлайн-поля | только мозг |
| `src/styles/<экран>.css`, `*.module.css` | стили экрана | исполнитель своего экрана |

Нужен новый токен или примитив — не заводи его у себя, напиши в отчёте, мозг добавит.

## 3. Поверхности — лестница светлоты

| Ступень | Токен | Цвет | Радиус | Тень | Где |
|---|---|---|---|---|---|
| Фарфор | `--page` | #e4e4e4 | — | — | фон под всем |
| Модуль | `--module` | #efefef | `--radius-module` 24 | `--shadow-inset` | колонка, секция, таблица, панель, группа списка |
| Плитка | `--module-card` | #fafafa | `--radius-tile` 20 | `--shadow-module` | карточка, строка-блок, метрика, контейнер строк таблицы |
| Всплывающее | `--card` / `--popover` | #ffffff | `--radius-popover` 16, диалог `--radius-dialog` 24 | `--shadow-overlay` | меню, поповер, диалог; фон плитки под курсором |

Правила:
- Рабочая область экрана **без подложки**: модули стоят прямо на фарфоре с зазором
  `--gap-module` (12px). Никаких белых полотен на весь экран, никаких `border-bottom`
  между шапкой, тулбаром и контентом.
- Разделитель внутри плитки — `1px solid var(--border)`. Рамка вокруг модуля или плитки
  не нужна: форму задают фон и тень.
- Вложенность не глубже «модуль → плитка». Плитка в плитке запрещена.

## 4. Цвет

- `--foreground` #262626 — основной текст. `--secondary-text` #666 — вторичный.
  `--muted-foreground` #a3a3a3 — только значки и плейсхолдеры, не для чтения.
- `--primary` лайм #d9f23b — **одно главное действие на экран** (кнопка «Новая сделка»,
  «Сохранить» в диалоге, «Применить» фильтра) и метка «КВАЛ». Текст на лайме — тёмный.
- `--info` #6d8cf0 — ссылки, «на сегодня», информационные точки. Синего как акцента нет.
- `--destructive`, `--success`, `--warning` — только по смыслу (ошибка, «просрочено»,
  «разговор состоялся», «ждёт»).
- `--overdue-gradient` — только счётчик «Просрочено». `--hero-gradient` — только первая
  метрика отчёта.
- Цвет этапа и статуса — пара `--hue-*-bg` / `--hue-*-tx`, точка — `--hue-*-dot`.
- **В экранном CSS нет hex и rgba** — только `var(--токен)`. Исключение: `#fff` в блике тени.
  Tailwind-классы `zinc-*`, `slate-*`, `gray-*`, `neutral-*`, `bg-white` → токены.

## 5. Типографика

- Шрифт Inter Tight (`--font-sans`). Точечный Doto (`--font-dots`, класс `.num-dots`) —
  **только итоги**: сумма колонки, значение метрики, большой счётчик. Не в таблицах.
- Заголовок экрана: `var(--text-title)` 26/32, вес **400**, `letter-spacing: -0.03em`.
- Заголовок модуля: 15px, вес 500. Текст: 13px (`--text-body`), мелкий 12px.
- Жирный — 500, не 600–700. Капс только в коротких метках (КВАЛ).
- Числа в таблицах — `font-variant-numeric: tabular-nums`.

радиус `--radius-control` (textarea — 14px), фон `var(--sidebar)`, без рамки,
фокус `border-color: var(--foreground); background: var(--card); box-shadow: 0 0 0 3px rgba(38,38,38,.08)`.

## 7. Рецепты экранов

### Шапка экрана
Высота `--h-header` 56, заголовок 26/400, иконка перед ним 18px. Счётчик «Показано N из M» —
`--secondary-text` 12px справа. Под шапкой — тулбар пилюлями (`.btn`, `.view-switch`),
справа поиск `.input` и главное действие `.btn-primary`.

### Таблица (сделки-таблица, контакты, звонки, аудит, корзина, настройки)
```
модуль (--module, radius 24, padding 6px)
└─ плитка (--module-card, radius 20, shadow-module, overflow hidden)
   ├─ шапка колонок: высота 36, текст --secondary-text 12px 500, фон плитки, sticky
   └─ строки: высота --h-row 36, разделитель 1px --border (последняя без),
      hover — background var(--accent), выбранная — var(--surface-select)
```
Пагинация и итог — под модулем пилюлями `.btn-ghost`, не внутри таблицы.

### Список с группами (задачи, инбокс, уведомления)
Группа = модуль: сверху заголовок модуля (15/500 + `.pill` со счётчиком) с отступом
10px 14px, ниже плитка со строками как в таблице. Между группами `--gap-module`.
Статус строки — точкой и цветом текста, не заливкой строки.

### Карточка записи (сделка, контакт)
Верхняя полоса «плашек» — ряд плиток (`.tile`, radius 20). Тело — две колонки-модуля:
левая `--module` с полями `.field-row`, правая `--module-card` с лентой; событие ленты —
плитка без тени (`background: var(--module-card)` внутри `--module`) или строка с разделителем.

### Настройки
Левое меню настроек — модуль с пунктами-пилюлями как в навигации (36px, активный —
белая пилюля с тенью). Контент — модули с плитками; таблицы — рецепт таблицы.

### Диалог и поповер
Вуаль `var(--scrim)` + класс `.motion-veil`. Окно — `--module-card`, радиус
`--radius-dialog` 24, тень `--shadow-overlay`, класс `.motion-dialog`, padding 20.
Заголовок 18/500. Кнопки внизу справа: `.btn-ghost` «Отмена» + `.btn-primary`.
Поповер/меню — `--popover`, радиус 16, `.motion-popover` или класс `.menu`.

### Вкладки
Сегмент `.view-switch`: пилюли 30px, активная — белая с `--shadow-pill`, неактивная —
`--secondary-text`, hover — `var(--ghost)`.

### Метрики (отчёты, дашборд)
Метрика — модуль radius 24 с `--shadow-module`, значение `.num-dots` 30px.
Первая метрика ряда — `--hero-gradient`, текст #17300f.

## 8. Движение — интерфейс должен ощущаться приятно

Токены: `--motion-fast` 120ms (наведение, нажатие), `--motion` 180ms (смена состояния,
поповер), `--motion-slow` 260ms (диалог, панель, появление), `--ease` — экспоненциальный
выход. Пружин, bounce и elastic нет. Анимируем только `transform`, `opacity`,
`background-color`, `color`, `box-shadow`, `border-color` — не `width/height/top/left`.

**Обязательно для каждого экрана:**

| Что | Как |
|---|---|
| Кнопка, пилюля, чип, пункт меню | hover: смена фона за `--motion-fast`; нажатие: `transform: scale(var(--press-scale))` (0.97) |
| Кликабельная плитка/карточка | hover: `translateY(var(--lift))` + `--shadow-module-hover` за `--motion`; нажатие: `scale(.99)` |
| Строка таблицы/списка | hover: `background: var(--accent)` за `--motion-fast`, без сдвига |
| Иконка в кнопке | hover: `scale(1.06)`; шеврон раскрытия поворачивается на 180° |
| Чекбокс, переключатель | нажатие `scale(.9)`; переключатель едет `transform`, не `left` |
| Меню, поповер, выпадашка | `.motion-popover` / `popover-in` за `--motion` от точки открытия |
| Диалог | вуаль `.motion-veil`, окно `.motion-dialog` |
| Боковая панель | `.motion-panel` |
| Список при первом показе | контейнер `.motion-list`, элементам `style={{ "--i": index }}` (лесенка до 12) |
| Появившийся блок (ошибка, подсказка, результат) | `.motion-fade-up` |
| Счётчик/бейдж | `badge-in` |
| Перетаскивание | поднятая карточка: `--shadow-drag`, `scale(1.02) rotate(1deg)`; место под перенос — `--surface-select` с плавной сменой фона |
| Фокус с клавиатуры | уже глобально: графитовое кольцо 2px |

Готово глобально, не дублировать: появление экрана при переходе, reduced motion
(`prefers-reduced-motion` гасит всё в `shell.css`), полоса перехода.

`transition: all` запрещён — перечисляй свойства.

## 9. Что нельзя

- Менять разметку, логику, данные, тексты. Разрешено в TSX только: добавить/заменить
  `className`, добавить `style={{ "--i": i }}` для лесенки, заменить Tailwind-цвета на
  классы-токены. Никаких новых компонентов, хуков, состояний.
- Новые `!important` (кроме переопределения инлайн-стиля сторонней библиотеки — с комментарием).
- hex/rgba в экранном CSS, `transition: all`, анимация размеров.
- Больше одной лаймовой кнопки на экран. Doto вне итогов. Синий как акцент.
- Трогать `tokens.css`, `shell.css`, `components.css`, `kit.css` и чужие экраны.
- Плотность ниже: строка таблицы 36, контрол 30, чип 26 — это закон.
