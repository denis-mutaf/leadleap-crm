# Контракт интерфейса LeadLeap CRM

Один закон для всех экранов. Всё, что ему противоречит, — дефект, даже если «работает».
Источник плотности и цвета — `ATTIO-DENSITY-SPEC.md` и `design/screens/_kit.css`.
Источник структуры экрана — `design/screens/<экран>.html` и `design/pagemaps/<экран>.md`.

## 1. Запрет мёртвого интерфейса

Элемент, который выглядит как контрол (кнопка, селект, чип фильтра, кебаб, стрелка),
**обязан работать**. Если функции нет — элемента нет. Никаких `<span class="static-filter">Фильтр</span>`.

## 2. Отклик

Любое действие пользователя даёт видимый отклик за 100 мс.

- Каждый маршрут имеет `loading.tsx` со скелетоном, повторяющим форму страницы
  (та же сетка, те же высоты строк), а не крутилку по центру.
  Без `loading.tsx` Next не префетчит динамический маршрут — это не украшение, а скорость.
- Пункт навигации, на который кликнули, подсвечивается сразу: `useLinkStatus` из `next/link`.
- Кнопка, запустившая запрос, переходит в `disabled` + меняет подпись («Сохраняем…»),
  а не остаётся активной.

## 3. Пустота

- **Поле видно всегда — в панели записи.** На экране сделки и контакта нет значения —
  показываем подпись и `—`, по клику открываем ввод. Поле не имеет права исчезнуть
  вместе с подписью: иначе карточка выглядит пустой и непонятно, что можно заполнить.
- **В списках и на карточках воронки правило обратное.** Там подпись без значения —
  это шум, который вытесняет полезное. Пустая строка не рисуется вовсе.
  Ни «Канал не указан», ни «Объект не указан», ни одинокий `—`: строка либо несёт
  факт, либо её нет. Исключение одно — последняя активность, она значима всегда.
- **Пустой список** = заголовок («Пока нет задач»), одна строка объяснения и действие.
  Голый белый прямоугольник запрещён.
- **Пустая колонка воронки** = тихая пунктирная зона с кнопкой «Сделка».
- Если данных нет, потому что канал не подключён, так и писать: «WhatsApp не подключён»,
  а не показывать пустой инбокс.

## 4. Редактирование

Всё, что показано в карточке, редактируется на месте:

- клик по значению → инлайн-контрол (text/select/date по типу поля);
- `Enter` сохраняет, `Escape` отменяет, потеря фокуса сохраняет;
- оптимистичное обновление, при ошибке — откат и тост с текстом ошибки;
- после успеха `router.refresh()` и короткий тост.

Смена этапа, ответственного, тегов и проектов доступна прямо из карточки, не только перетаскиванием.

## 5. Движение

Токены (объявлены в `globals.css`, использовать только их):

```css
--motion-fast: 120ms;
--motion: 180ms;
--motion-slow: 260ms;
--ease: cubic-bezier(.2, 0, 0, 1);
```

- Модальное окно: вуаль `opacity 0→1` за `--motion-fast`; окно
  `translateY(6px) scale(.98) → none` за `--motion`.
- Боковая панель: `translateX(100%) → 0` за `--motion-slow`.
- Раскрытие блока: `grid-template-rows 0fr → 1fr` за `--motion`.
- Скелетон: бегущий блик 1.2 с, `--muted` → `--accent` → `--muted`.
- Наведение и фокус: `background-color`/`border-color` за `--motion-fast`.
- Всё движение внутри `@media (prefers-reduced-motion: reduce)` отключается.

Анимация не задерживает данные: скелетон показывается сразу, без задержки-«антимигания».

## 6. Плотность

Высоты только через токены: контрол 28, компактный контрол 26, строка таблицы 36,
шапка колонок 39, шапка страницы 48, полоса действий 49, боковой отступ ячейки 12, радиус 6.
Основной текст 14/20, вторичный и заголовки колонок 13/18 цветом `--secondary-text`,
тихий текст `--muted-foreground`. Никаких литералов 34px, 44px, 48px в строках и контролах.

## 7. Цвет как сигнал

- Синий `--primary` — единственный акцент: активное действие, выбранное состояние.
- Красный `--destructive` — только разрушающее действие и просроченная задача.
- Янтарный — только просрочка по времени. **Нельзя** красить им нормальное состояние
  вроде «следующий шаг не назначен»: если так покрашена половина экрана, это не сигнал.
- Серый `--secondary` — отложенное, выключенное, историческое.

## 8. Карточка сделки в воронке

Порядок строк: контакт и канал → объект → проекты и метки → деньги (ежемесячный платёж и
первый взнос) → низ: аватар ответственного и **строка последней активности**
(что произошло и когда). Отсутствие следующего шага помечается тихой точкой у аватара,
а не янтарной плашкой. Клик по любому месту карточки открывает сделку.

Каждая строка, кроме имени и последней активности, рисуется только если у сделки
есть это значение. Карточка из имени, метки и строки активности — нормальная
карточка; карточка из имени и трёх сообщений «не указан» — нет. Ничто на карточке
не обрезается многоточием посреди слова: не помещается — значит, этой строке там
не место.

## 9. Иконки

Только Lucide (`lucide-react`, 1.47.0), размер 14–16 внутри строк и контролов.
Свои `<path>` рисовать запрещено. Мессенджеры помечаются `message-circle`,
точный канал пишется словом.
