# CRM отдела продаж застройщика

Рабочее место отдела продаж ISRAGRUP: приём обращений из телефонии, мессенджеров и форм,
ведение сделки по одной воронке на два проекта, отчётность по каналам и когортам.
Заменяет amoCRM. Шахматка, договоры и деньги живут во внешнем софте и в эту систему не входят.

## Language

### Люди и работа с ними

**Контакт**:
Человек, с которым говорит отдел продаж. Может иметь несколько телефонов и несколько
профилей в мессенджерах.
_Avoid_: клиент, лид, карточка клиента

**Сделка**:
Работа с одним контактом по покупке — от первого обращения до договора. У контакта может
быть несколько сделок одновременно.
_Avoid_: лид, заявка, карточка сделки

**Обращение**:
Сырое входящее событие из канала — звонок, сообщение, заявка формы, заявка Lead Ads.
Из обращения рождается новая сделка или оно дописывается в существующую.
_Avoid_: лид, вебхук, событие

**Ответственный**:
Менеджер, ведущий сделку. Назначается вручную.
_Avoid_: владелец сделки, исполнитель

**Общий котёл**:
Сделки без ответственного, куда падают все новые обращения.
_Avoid_: неразобранное, входящие

**Слияние**:
Ручное объединение двух контактов в один с сохранением истории обеих сторон.
_Avoid_: мердж, склейка дублей

### Движение по воронке

**Этап**:
Позиция сделки в воронке. Состав и порядок этапов настраивает администратор.
_Avoid_: стадия, статус, колонка

**Статус**:
Состояние сделки независимо от этапа: в работе, выиграна, проиграна, отложена.
_Avoid_: состояние, флаг

**Переход**:
Запись о смене этапа: сделка, откуда, куда, когда, кто. Хранится отдельной строкой
и никогда не перезаписывается — на ней стоит вся отчётность.
_Avoid_: история, лог этапов, изменение

**Квалификация**:
Набор обязательных полей о покупателе — бюджет, способ оплаты, срок покупки,
диаспора или местный, комнатность, цель покупки. Без них сделка не идёт дальше.
_Avoid_: анкета, брифинг

**Следующий шаг**:
Задача с конкретной датой, без которой сделку нельзя перевести на следующий этап.
_Avoid_: активность, дело, напоминание

**Касание**:
Запланированный контакт с покупателем по отложенной сделке. В названную дату
ответственному автоматически создаётся задача.
_Avoid_: follow-up, пинг

**Причина отказа**:
Значение из закрытого справочника, обязательное при закрытии сделки как проигранной.
_Avoid_: комментарий к отказу

**SLA первого ответа**:
Срок от появления обращения до первого ответа менеджера. Просрочка эскалируется руководителю.
_Avoid_: таймер, дедлайн

### Предмет продажи

**Проект**:
Жилой комплекс застройщика — Select New Town или Next New Town. У сделки может быть
выбрано оба: покупатель рассматривает обе площадки в одной сделке, без дубля.
_Avoid_: комплекс, объект, направление

**Объект**:
Интересующая покупателя квартира, записанная текстом. Шахматка, статусы квартир, брони
и цены живут во внешнем софте — система их не знает.
_Avoid_: квартира, лот, юнит

### Каналы и общение

**Канал**:
Способ связи с покупателем: телефония, WhatsApp, Viber, Instagram, Facebook, форма сайта.
_Avoid_: интеграция, мессенджер

**Источник**:
Откуда пришло обращение, в разрезе которого считается реклама: канал плюс UTM-метки
и ID кампании Meta.
_Avoid_: откуда узнал, кампания

**Диалог**:
Переписка с контактом в одном канале, собранная в единый инбокс внутри системы.
_Avoid_: чат, тред, переписка

**Звонок**:
Разговор, случившийся на стороне Moldcell PBX и привязанный к контакту, а при выборе
менеджера — к одной из его сделок. Запись разговора хранится у оператора.
_Avoid_: вызов, call

### Настройка системы

**Пользовательское поле**:
Поле карточки, которое администратор заводит сам, без разработчика: текст, число, дата,
список, чекбокс.
_Avoid_: кастомное поле, доп. поле

**Тег**:
Метка из справочника, свободного ввода нет. Заводить новые теги может только руководитель.
Через теги размечаются рефералы.
_Avoid_: метка, лейбл, категория

**Роль**:
Право доступа: менеджер видит только свои сделки, руководитель — все, застройщик — только
сводный дашборд, администратор настраивает поля и справочники.
_Avoid_: группа, права, уровень доступа
